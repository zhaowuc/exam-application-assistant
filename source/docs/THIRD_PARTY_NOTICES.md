# 第三方组件

运行组件包括 Python、Django（BSD）、Django REST Framework（BSD）、Simple JWT（MIT）、Waitress（ZPL）、OpenPyXL（MIT）、PyJWT（MIT）、Vue（MIT）、Vue Router（MIT）、Lucide（ISC）及相应传递依赖。

构建组件包括 Vite、esbuild、Prettier 与 PyInstaller。PyInstaller 引导器的许可带有允许发布被打包应用的例外。实际版本参见两个锁定文件。

发布脚本将已安装依赖中的 LICENSE、COPYING 等文件收集到运行包的 licenses 目录。系统字体使用 Windows 已安装字体；没有打包 Apple SF 字体、Apple 图标或商标素材。
