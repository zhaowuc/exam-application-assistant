# lixianhang · 报考小助手

报考小助手离线重构版的开源项目，包含 Django 后端、Vue 前端及 Windows 启动与打包脚本。

## 源码与运行

完整源码位于 [`source/`](source/)，开发安装、运行及打包说明见 [`source/README.md`](source/README.md)。

在 `source` 目录运行 `setup_source.cmd` 安装开发依赖，然后运行 `start_source.cmd` 启动系统。

仓库保留源码附带的演示种子数据；本地数据库、密钥、虚拟环境、测试工作目录和离线运行包不纳入版本控制。
