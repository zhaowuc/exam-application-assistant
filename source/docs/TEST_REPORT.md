## 测试中发现并修复

1. 重复报考/收藏引发事务错误：保存操作加入事务隔离，失败后可继续请求。
2. Windows 恢复数据库时连接未关闭：SQLite 连接明确关闭，避免临时文件被占用。
3. 冻结包未包含动态导入的业务模块：打包显式收集 config/core/services 与迁移。
4. 后台编辑后的分页参数传入 Ref 对象：修正为实际页码，保存后正确刷新。
5. 动态表单的 select 可访问名称包含选项正文：为生成控件设置清晰名称。
6. 推荐权重名称与原种子不一致：capacity/history_score 映射到名额/历史成绩，保留院校维度。
7. 导入试卷编排后总题数和总分未同步：导入时重新汇总。
8. 增加每题停留时间记录；提交时上报，不以该客户端统计作为判分依据。
