# 功能对照与验收范围

按用户提供的结构图逐项核对，两个圈定缺项已补齐。

| 图中模块 | 重构实现与页面入口 | 验证方式 |
| --- | --- | --- |
| 用户登录、注册 | /login，JWT、密码修改、停用与版本撤销 | 后端回归、浏览器登录 |
| 首页资讯、信息展示 | /，/notices，公告详情 | 浏览器、API |
| 公务员报考 | /catalog/civil，条件筛选、详情与历史 | 浏览器、API |
| 事业单位报考 | /catalog/institution | 浏览器、API |
| 研究生报考 | /catalog/graduate | 浏览器、API |
| 智能推荐、匹配推荐管理 | /recommendations，详情资格检查，后台规则与权重 | 回归、浏览器 |
| 在线刷题、题库试卷管理 | /practice，自主组卷，后台题库、知识点与试卷编排 | 回归、浏览器 |
| 考试成绩管理 | /exam/:id，/scores，后台考试成绩 | 判分、超时、重复交卷回归 |
| 消息提醒、通知管理 | /notifications，订阅、计划日期与处理通知 | 回归、浏览器 |
| 个人中心 | /profile，档案、偏好与账号安全 | 回归、浏览器保存 |
| 用户权限管理 | /admin/users，管理员保护、角色与停用 | 回归、浏览器 |
| 招考信息管理 | /admin/opportunities，三类详情、历史数据 | 回归、浏览器 |
| **公共服务（原缺项）** | /services，离线指南、材料清单、FAQ、入口、本地咨询与回复 | 提交与回复真实浏览器流程 |
| **报考数据管理（原缺项）** | /applications 与 /admin/applications，提交、完善、审核、材料、成绩、结果、筛选、导出 | 权限与重提回归、真实审核与导出 |
| 系统运行管理 | /admin/operations，服务状态、备份恢复；设置与审计 | 重启、恢复黑盒测试 |

补充：收藏、2–4 目标比较、计划编辑、错题掌握标记、薄弱项分析、XLSX 导入模板与逐行错误报告均可使用。客户运行包包含解释器与所有运行资源，不要求客户安装开发工具。

“移动端”在本版本指同一 Web 界面的响应式小屏视图，不是独立 Android/iOS 原生安装包。默认仅监听本机地址，手机不能通过局域网直接连接这台电脑。

当前仍有明确边界：本地演示数据、不实时获取公告；无真实官方报名、短信、云同步；外部官方网站必须联网；数据规模上限见 README。本次没有声称未知机器、所有数据和所有边界输入都“完美”。
